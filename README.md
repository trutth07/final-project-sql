## 📊 SQL-аналитика

В рамках проекта проведен комплексный анализ клиентской базы и транзакционной активности за период с **июня 2015 по июнь 2016 года**.

### 🎯 Основные направления анализа:
1. **Когортный анализ лояльности:** Выделение клиентов с непрерывной историей покупок (13 месяцев подряд) и расчет их ценности (LTV, средний чек).
2. **Динамика ключевых метрик:** Ежемесячный мониторинг среднего чека, количества активных пользователей и интенсивности операций.
3. **Структура выручки:** Анализ помесячных долей операций и оборота с применением оконных функций (`OVER`).
4. **Демографический анализ:** Оценка гендерной структуры клиентов и распределения объема продаж по полу.
5. **Возрастная сегментация:** Группировка клиентов по 10-летним возрастным когортам и анализ их вклада в квартальную выручку.
